This repository is a broad MCM/ICM preparation archive. It contains original modeling skills and source-code-style examples as well as broader reference materials such as problem statements, papers, templates, datasets, PDFs, and other study resources.

## Clean Skills-Only Repository

For reusable MIT-licensed skills, scripts, examples, and documentation, use the clean skills-only repository:

[SPIRAL-EDWIN/Skills-for-Math-Modeling-MCM-ICM](https://github.com/SPIRAL-EDWIN/Skills-for-Math-Modeling-MCM-ICM)

That repository removes third-party and binary reference materials so downstream users can work with the original skills under a clearer license boundary.
